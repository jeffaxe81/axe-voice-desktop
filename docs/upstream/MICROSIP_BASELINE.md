## Licenciamento

A página oficial do MicroSIP informa distribuição do source sob GNU GPL v2.

O MicroSIP depende de bibliotecas de terceiros que não estão incluídas no arquivo de source, portanto o ambiente de build exigirá inventário e obtenção das dependências separadamente.

O PJSIP adota licenciamento dual: GPL v2 ou posterior, ou licença proprietária alternativa. As implicações de redistribuição deverão ser validadas antes de qualquer versão comercial/fechada.

## Regras para importação

1. Obter o arquivo diretamente da origem oficial.
2. Não modificar o conteúdo durante a primeira importação.
3. Preservar todos os avisos de copyright e licenças.
4. Registrar hash SHA-256 do arquivo obtido.
5. Importar o source em commit exclusivo.
6. Criar uma tag de referência após a validação.
7. Não aplicar branding antes do primeiro build funcional.
