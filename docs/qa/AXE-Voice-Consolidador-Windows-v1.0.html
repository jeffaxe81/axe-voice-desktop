5. Critérios de aceite

O painel recalcula o aceite local usando resultados obrigatórios, problemas e assinatura do responsável; não confia no campo de aprovação declarado no JSON. Uma ficha incompleta ou com problemas não é aprovada.

Não é um certificado de produção: aceite de engenharia via CI, teste físico local e homologação de telefonia real têm estados separados. O aceite no PABX real permanece não realizado.
