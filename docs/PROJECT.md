# Projeto AXE Voice Desktop

## Objetivo
Customizar progressivamente um softphone SIP desktop baseado no MicroSIP/PJSIP, mantendo rastreabilidade do upstream, build reproduzível e evolução por microentregas.

## Escopo do Projeto 1
1. Fundação do repositório.
2. Baseline oficial do MicroSIP.
3. Ambiente de build.
4. Compilação do upstream sem alterações.
5. Validação SIP e áudio.
6. White label.
7. Simplificação de interface.
8. Provisionamento e integrações futuras.

## Fora do escopo inicial
- aplicativo Android/iOS;
- backend de provisionamento;
- integrações CRM/Despacho;
- distribuição comercial.

Esses itens permanecem no roadmap, mas não devem interromper a etapa atual.
