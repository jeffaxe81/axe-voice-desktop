# Native contact book0.69 — ten functional delivery fronts

User explicitly requests ten delivery fronts focused on features, not test workstreams. Deliver a modeless native contact book with ten usable capabilities: add, edit, delete with confirmation, search by name/destination, favorite toggle, favorites-only filter, fill dialer without calling, explicit clipboard copy, reviewed JSON import and JSON export. Contacts persist per user separately from SIP credentials. No account/password stored, logged or exported. Root integrates main button CONTATOS/Ctrl+J and ensures contact window keyboard messages do not invoke main call accelerators. Main timers/call UI stay responsive; contact window does not disable owner.

Stable in-memory IDs never reused; atomic edits. Search case-insensitive basicLatin/Latin1, favorites first then name. JSON strict version1 object {version:1,contacts:[{name,destination,favorite}]}, UTF8,512KiB cap; reject malformed/duplicate keys/unexpected schema/trailing data. Import previews count and adds nonduplicates transactionally; never silently replaces existing contacts. Export via explicit file chooser/overwrite confirmation. Data is readable local JSON backup, not credential storage.
