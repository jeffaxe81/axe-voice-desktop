# Candidate0.55 — incoming-call ringtone

Add a quiet repeated local 250ms tone to verified native incoming calls only. Reuse the existing WASAPI render-only beep, never microphone/RTP/SIP. The selected ringtone output is independent of the fixed conversation route. Native ringtone selector gets an explicit Windows multimedia-default entry; explicit missing IDs are preserved, never silently replaced. Default mode follows Windows multimedia role.

Chosen design: a separate single render worker with injected platform render port and cooperative atomic cancellation. UI synchronization carries only opaque session/call IDs and an endpoint; generation changes cancel obsolete work and reject stale results. The UI never waits for rendering while answering/hanging up. Stop on non-Ringing/invalid proof, call replacement, answer/decline intent, native stop and shutdown. Acknowledging an answer/decline suppresses alert for that call even if the command fails, leaving visual incoming state; a new call rings normally. Bind answer/hangup UI actions to the displayed observation so a stale click cannot affect another call.

The renderer checks cancellation before initialization/start, each packet and drain wait; pending initialization checks cancel immediately before starting output. Cancellation racing a device API follows that API and driver latency. Audio API/driver blocking and actual audible stop timing remain hardware acceptance, not a software deadline claim. Shutdown requests cancel then joins. Preview sound is canceled/disabled during a verified incoming call; unattended smoke never plays audio.

Validation: pure incoming/provenance/identity/default/no-fallback policy; deterministic worker tests using a cooperative render fake for cancellation, replacement, errors, route changes and shutdown; Windows pre-canceled real-render smoke that never opens hardware; native GUI and no-call command checks; existing Windows/native/installer gates. No actual PBX/headset audibility claim, SRTP or call-waiting alert for outgoing progress.
